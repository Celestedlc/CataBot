# CataBot
A Personal Assistant Agent designed to work inside a Raspberry Pi Zero2W running locally using TensorFlow Lite.


To-Do list:

- [] Text support for simple instructions
- [] Telegram Integration
- [] Voice Commands
- [] TTS


This version has responses to "hello" and "bye". 
To train the model locally, run rawBuild.py
You can use the included cataBot.tflite with client.py to try it.
